Financial Harness

Stock prices, company reports and calculations in one chat.

Every result can show where the data came from and which assumptions were used.

What users can ask

  • How did IBM’s price and trading volume move?
  • What did IBM report for earnings and valuation?
  • How did two stocks compare on the same dates?
  • What happens to a position if the price changes?

From question to answer

React sends the question to FastAPI. Celery picks it up from Redis and fetches stock data through MCP tools.

The Python sandbox calculates the answer. Redis saves it so the browser can retrieve it by job ID.

Demo

  1. Ask for IBM’s price and volume. Hover over a candle.
  2. Ask for earnings and valuation. Point out the reporting period and source.
  3. Ask what happens if $1,000 drops 10%. Show the progress and $900 result.
